# Computación-Cuántica-2

Aquí se encuentran los Jupyter Notebooks que he estado desarrollando a lo largo de las semanas para computación cuántica 2 con el profeor Salvador Elias 
Venegas-Andraca con intenciones de ayudar a mis estudiantes a familiarizarse con la metodología de estudio de los algoritmos cuánticos,  y sintetizar toda la 
información en una carpeta. Los notebooks y la teoría se basa en las notas manuscritas sobre las cuales estoy trabajando.
